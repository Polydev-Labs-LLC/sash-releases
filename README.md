# Sash releases

Downloads of **Sash for Mac**, made by Polydev Labs, LLC. This repository holds release files only (the DMG, the update archive and its
signed manifest, release notes). There is no source code here.

- **Install:** open the latest [release](../../releases/latest), download the `.dmg`, open it and drag Sash to Applications.
  The app is signed with Developer ID (Polydev Labs, LLC, team `GQYQPL4C53`) and notarized by Apple.
- **Update:** Sash checks this repository once a day and installs a new version only if Apple's signature and notarization and
  Sash's own update signature all check out. Settings > General has the switches and "Check Now".
- **Verify a download:** `SHA256SUMS` lists the checksum of every file of a release.

Sash is open source software built on [Sill](https://github.com/Saffsanity/sill) (Apache License 2.0); the licenses ship inside the app
(Sash > Open-Source Licenses).
